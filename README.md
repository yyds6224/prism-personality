# 棱镜 PRISM · GitHub Pages

静态网站包为 site.zip，不含用户答题记录、凭据或 QA 截图。原始许可与署名在压缩包的 ATTRIBUTION.md 和 LICENSE 中。

部署到默认分支 main 的公开仓库。Settings → Pages → Source 选择 GitHub Actions，运行 `.github/workflows/pages.yml`。工作流会解包网站并部署，不安装第三方应用依赖。

GitHub Free 的 Pages 可用于公开仓库。访问地址以 GitHub 返回的实际部署地址为准。是否适合国内朋友使用，需部署后用他们的实际网络验证，不承诺全部国内线路可用。
